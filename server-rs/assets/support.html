Поддержка Hegai Code

Напишите на info@a.test. Укажите версию приложения, модель iPhone и шаги, после которых возникла проблема. Не присылайте токены входа, ключи API или закрытый код.

Подключение

Для работы нужны аккаунт с доступом к хабу и подключённый компьютер с настроенным Claude Code или Codex. Вход в приложение не устанавливает агента на компьютер и не предоставляет подписку AI-провайдера. Права на машины и проекты выдаёт владелец рабочей среды.

Удаление аккаунта и данных

Откройте Настройки → Аккаунт → Удалить аккаунт. Если войти не удаётся или удаление остаётся в обработке, напишите в поддержку с тем способом входа, которым вы пользовались. Мы проверим владение аккаунтом; пароль или токен в письме не нужен.

Согласие на AI

В Настройках → Аккаунт → Конфиденциальность можно прочитать раскрытие передачи данных и отозвать согласие. Передача новых AI-запросов из приложения остановится. Уже запущенную работу останавливайте в соответствующей сессии.

Hegai Code support

Email info@a.test with the app version, iPhone model and reproduction steps. Do not send passwords, session tokens, API keys or private source code.

A hub account with access to a connected computer and a configured coding runtime is required. Signing in does not install the agent or provide an AI subscription. Your workspace owner manages device and project access.

To delete your account, open Settings → Account → Delete account. If you cannot sign in or deletion remains pending, contact support using the identity associated with your account. We verify ownership without asking you to send a password or session token.

AI consent can be withdrawn under Settings → Account → Privacy. Stop any existing remote work from its session separately.
