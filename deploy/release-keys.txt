# One key per line: base64 of the SPKI DER encoding of an Ed25519 public key

# comments. Compiled into the external agent bundle (deploy/build-agent.sh) and

# Rotation is a list, not a swap: add the new key, ship a release signed with
# the OLD key that trusts both, let the customers approve it, then sign with the
# new key. Removing the only key an agent trusts strands that agent.
#
# An external agent with an empty list never self-updates and an external hub
# offers no bundle as valid. Keys are made offline with
# deploy/release-signer/offline-sign.mjs setup (README there).
