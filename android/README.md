## Возможности

- Вход через Google в Custom Tabs и одноразовый код с S256 PKCE. Свой сервер
  (external edition): по `/api/public-config` кнопка «Войти» открывает
  `<hub>/native-signin` с теми же PKCE-параметрами (пароль + код, OIDC); сессия
  хранится вместе с хабом, который её выдал (`SessionBinding`), чужая не используется.
  Сессия хранится в Keystore; экспортируемый URI не содержит bearer-токен.
  Telegram: native start/poll, сверка числа, карточка вошедшего аккаунта.
  В настройках — привязанные способы входа, добавление Google/Telegram и отвязка.
- Claude/Codex: проекты и свои сессии, создание/клонирование проекта, история,
  потоковый ответ, остановка, ввод во время работы, Markdown с выделением текста,
  вопросы с несколькими вариантами, подтверждение плана и разрешения инструментов.
- Галерея/файлы/камера (изображения), Android «Поделиться», диктовка через
  серверное распознавание с обработкой текста и повтором сохранённой записи;
  системный SpeechRecognizer остаётся в настройках. Модель/effort/права,
  контекст и подтверждаемое сжатие.
- Read-only mirror, явный takeover, переименование/поиск/экспорт/завершение сессии,
  автоматические названия и быстрые ответы с точным видимым текстом,
  входящие события своих сессий, межустройственные реплики и прочтение.
- Генерируемые картинки, помощники с отдельным разговором и остановкой,
  завершение хода и «Продолжить» с сохранением черновика.
- Отчёты с изолированным просмотром HTML, доска этапов, избранное и
  загрузка последних разговоров для чтения без сети; пустые проекты на полке.
- Передача данных AI разрешается отдельно для проверенного аккаунта;
  без согласия можно читать историю и останавливать работу.
- Аккаунт, пространства, тема, лимиты, устройства и подключение машин,
  оборудование/процессы, память, профиль, команда/приглашения/роли/проекты/аудит.
- Зашифрованный долговечный кэш истории, черновиков и изображений, отдельно
  для каждого аккаунта и пространства. Отправка сначала записывается на диск.
  После разрыва связи сообщения **не отправляются повторно автоматически**.
- FCM data-only push с переходом в сессию и действиями подтверждения после
  разблокировки. На Android до 12 действие открывает подтверждение в приложении.
  Без конфигурации Firebase переключатель push недоступен; socket не заменяет push.

## Сборка и проверки

JDK 17, Android SDK Platform 36 / Build Tools 36.0.0 (targetSdk 36). AGP 8.13,
Kotlin 2.2, Gradle Wrapper 8.14.5 закреплён SHA-256. Compose BOM 2026.06 +
Material 3 1.5.0-alpha18 (Expressive): alpha19+ требует compileSdk 37 и AGP 9.1. Для распространения APK напрямую; Play-релиз требует
отдельного обновления target SDK по требованиям магазина.

```sh
npm run build --workspace shared
./android/gradlew -p android :core:test :app:assembleDebug :app:lintDebug
node android/scripts/check-protocol.mjs
./android/gradlew -p android :app:connectedDebugAndroidTest
```

SDK задаётся `ANDROID_HOME` или игнорируемым `android/local.properties`.
APK: `android/app/build/outputs/apk/debug/app-debug.apk`.
Подписанный release:

```sh
HEGAI_ANDROID_SIGNING_PROPERTIES=/secure/path/release.properties \
  ./android/gradlew -p android :app:assembleRelease
```

Файл подписи вне репозитория содержит `storeFile`, `storePassword`, `keyAlias`,
`keyPassword`. Ключи, пароли и сессии в APK/репозиторий не включаются.
Публикация и Firebase: deploy/ANDROID.md.

## Устройство и границы

`core/` — чистый JVM HubEngine, модели и корреляция RPC; `app/` — Compose,
OkHttp, системные интеграции и Keystore. Контракт в `shared/`.
Просмотр вызывает только чтение/subscribe/mirror; писатель создаётся по отправке.
Поколение соединения отсекает поздние callbacks; bootstrap аккаунта заканчивается
до первого socket. Snapshot другого аккаунта/пространства сбрасывает контекст.

Кэш — AES-GCM с scope в AAD, AtomicFile в noBackupFilesDir. Ревизия записи
предотвращает перезапись checkpoint старым отложенным сохранением. Восстановление
закрывает ввод до завершения. Logout очищает кэш, а потеря доступа очищает
текущий scope и сохранённую offline identity. Непоместившиеся восстановленные
изображения остаются в неподтверждённой отправке до освобождения места.

Custom Tabs принимает только совпавший state, код64hex и handshake до10мин;
серверный код одноразовый, живёт2мин. Только private verifier позволяет обмен.
FCM сервисный аккаунт находится исключительно на хабе. Push адресован владельцу
run, отозванный community access проверяется перед постановкой/отправкой.
