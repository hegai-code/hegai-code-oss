# Проверка требований из беседы — 23.09.2026

Один итоговый выпуск после общей проверки. Более поздние уточнения пользователя
заменяют ранние: заголовок короткий, но сохраняет предмет; токены всего хода,
а не оценка ответа; прозрачные области вокруг островов; диктовка вместе с фото.

| Требование | Что проверяется |
| --- | --- |
| Изучить документацию, рефакторинг с пользой | CLAUDE, DESIGN, REBUILD, CONTRIBUTING; границы состояния и регрессии |
| Быстрое меню при свайпе вправо, кэширование | 1000 сессий, подготовленный DrawerModel, жест без перестроения списка; ограниченный прогрев истории |
| Меню как ChatGPT | Сдвиг страницы за пальцем, поиск и собственные сессии по проектам, без списка Memory/Flow |
| Сохранность набранного текста | Перезапуск, смена сессии/проекта/аккаунта, появление постоянного id новой сессии |
| Заголовок сессии вместо модели | История, смена модели, новый разговор, повторное открытие; осмысленные целые слова |
| История открывается внизу и не исчезает | 1000 сообщений разной высоты, переходы между сессиями, догрузка, чтение во время генерации |
| Модель, effort и контекст снизу | Основная и только что созданная сессия, сохранность черновика при открытии настроек |
| Компактные шестерёнки, без completed | Одна метка сбоку от последней реплики; детали открываются при клавиатуре |
| Нет пустой серой отправки | Пустой текст, пробелы, фото; поле компактно до взаимодействия |
| Волна на всю ширину, заметная громкость | Геометрия и шкала речи; физический микрофон требует отдельной проверки на устройстве |
| Claude оранжевая молния, Codex чёрная | Шапка и список, появление/исчезновение по working |
| Бургер с большой областью нажатия слева | 56×44pt, остров 44pt, оба края кликабельны |
| Steer в работающий Codex | Агент отправляет turn/steer, UI не обещает ожидание конца хода |
| Переносы после 4–6 строк | Рост до 6 строк, каретка видна, ручной скролл черновика |
| Промежуток между моделью и отправкой | Узкий экран, клавиатура, диктовка и контекст одновременно |
| Единая прозрачная верхняя/нижняя область | Чат и меню, обе темы; локальные острова сохраняют читаемость |
| Кольцо контекста и compact | Показания сервера, лист сжатия, подтверждение результата и сохранность черновика |
| Клавиатура закрывается первым тапом | Текст/пустая область чата и элементы сообщений |
| Время работы и все токены | Только данные usage от runtime, без оценки длины ответа; таймер |
| Лимиты в настройках и новой сессии | Claude/Codex/Gateway/личный бюджет, даты сброса |
| Форматирование как в чате | Markdown при генерации и после, абзацы и переносы |
| Названия меню крупнее, без лишнего отступа | 17pt, общий левый край проекта и сессии |
| Стоп сохраняет последнее слово | Окно финализации, поздние callbacks, ошибка/таймаут без автоотправки |
| Стоп и отправить — разные действия | Проверка текста после стопа; стрелка ждёт финальной расшифровки |
| Фото не блокирует микрофон | Фото + текст + диктовка + отмена/повтор + отправка |
| Крестик отмены записи | Возврат исходного текста и фото, отмена отложенной отправки |
| Не показывать чужой Circle | Владелец истории/рана, общий сервер, поиск, связанные списки и фоновый кэш |
| Вопрос о 250k у Astra | Кольцо отражает окно конкретной сессии из Codex, а не паспортный максимум модели |

Сообщения «так не должно быть» без доступного изображения проверяются по
соседним текстовым уточнениям. Новые детали отсутствующего изображения не
восстанавливаются догадками.

## Результаты

- До изменений: 272 модульных теста прошли.
- После исправлений: 273 модульных теста; 37 различных UI-сценариев
  (итоговые результаты после повторов исправленных AX-проверок).
- Codex steer: 11 тестов агента. Код агента в этом выпуске не менялся;
  автоматический steer и полная статистика требуют работающего агента 0.3.2.
- Длинная история: 1000 сообщений разной высоты, смена сессии, загрузка
  предыдущих сообщений и чтение во время нового ответа — 3 UI-теста.
- Диктовка: стоп/отправка/ошибка, отмена ожидающей отправки, фото вместе с
  текстом и голосом; дополнительно присвоение id новой сессии во время записи.
- Drawer: 1000 сессий, поиск, проекты, избранное, медленный свайп вправо,
  доступность закреплённых контролов после прокрутки и фильтр владельца.
  В симуляторе замер callback после открытия: 12.8 мс, max gap 18.1 мс,
  0 перестроений полки. В медленном свайпе 61 событие, max gap 17.2 мс,
  Drawer body изменился один раз, не на каждое движение пальца.
  Это callback/main-run-loop диагностика, не замер GPU или физического iPhone.
- Визуальная проверка: снимки UI-тестов и shoot.sh на 375/430pt, обе темы.
  Новый разговор проверен на обоих размерах, включая нижние настройки.
- Физический микрофон и качество распознавания реальной речи здесь не
  проверялись: Speech в UI-сценариях подменяется управляемым стендом.

## Исправления по итогам общей проверки

1. Черновик нового разговора больше не исчезает при session_started.
   Ключ закрепляется за своим разговором, диктовка переживает назначение id.
2. Новый разговор получил меню, нижние настройки модели/effort и заголовок
   по первому сообщению. Открытие этой же сессии сохраняет живую подписку.
3. Личный список проекта и фоновый прогрев применяют общий фильтр владельца:
   чужие сессии не расходуют ограниченный автоматический кэш.
